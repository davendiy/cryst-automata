From Table~\ref{tab:case1_srdegrees0} we obtain a single triple $p_\sigma, q_\sigma$ and $g_\sigma$ that
describes $SRD$ via the equation (\ref{eqn:space_case2}):
\[
  p_\sigma(y_0 \dots y_4) = 2y_2 + 1,  \quad q_\sigma(y_0 \dots y_4) = -y_1 y_3 + y_0 y_4
\]
\[
  g_\sigma(y_0 \dots y_4) = y_0 + y_4.
\]
It is clear that the pair $(q_\sigma, g_\sigma)$ falls into the special case for the plane groups Nos.1 and 2, and every
integer $d \ge 2$ occurs in the set \\
$\{ | q_\sigma(y_0 \dots y_4) | \, : \, q_\sigma(y_0 \dots y_4) \notin \{0, 1, -1\}, (q_\sigma \pm g_\sigma)(y_0 \dots y_4) \neq -1 \}$.
Combining with the condition $p_\sigma(y_0 \dots y_4) \notin \{0, 1, -1 \}$ we get the following description of $SRD$:
$$
SRD = \{(2k + 1)(m + 1) \, : \, k,m \in \mathbb{N} \} = \{6, 9, 10, 12, 14, 15, 18, \dots \},
$$
which is, similarly to the plane group $p2mg$ from the previous section, the set of all composite positive integers that
are not powers of 2. In particular, the minimal self-replicating degree is 6.
